Как перейти с Element на VaVsta Messenger и не потерять переписки

VaVsta Messenger — это тот же Matrix, что и Element. Переписки хранятся на сервере и при установке нового приложения никуда не денутся. Логин и пароль те же (@user:chat.vavsta.ru).

Риск потерять — только зашифрованные сообщения. Чтобы новое приложение могло их прочитать, ему нужны ключи. Есть два законных способа их получить:

  • Key Backup — серверная резервная копия ключей. Открывается вашим ключом восстановления (recovery key) или паролем аккаунта;
  • подтверждённое старое устройство — вход подтверждается со старого Element, и ключи переезжают на новое устройство.

⚠️ VaVsta Messenger не умеет импортировать файлы ключей .keys из классического Element. Рассчитывать надо только на Key Backup / recovery key.

1. В старом Element проверьте Key Backup (до установки!)

  1. Element → Настройки → Безопасность и конфиденциальность → Шифрование.
  2. Раздел Key Backup:
    • статус «Выполняется» — отлично, сверьте только, что у вас сохранён ключ восстановления. Если нет — запишите его;
    • статус «Отключён» — создайте бэкап и сохраните сгенерированный ключ в надёжном месте (бумага, менеджер паролей).
  3. Желательно проверить ключ на практике: восстановите его обратно (Element это умеет). Не подошёл — создайте новый и сохраните заново.

2. Установите VaVsta Messenger

Скачайте APK здесь же на странице приложения или в разделе Releases на GitHub. Можно установить поверх Element — оба будут работать параллельно.

3. Войдите и восстановите ключи

  1. Откройте VaVsta Messenger. Сервер уже подставлен — chat.vavsta.ru.
  2. Введите логин и пароль.
  3. Сразу после входа приложение предложит восстановить ключи:
    • ввести ключ восстановления (recovery key) — надёжнее всего; или
    • ввести пароль аккаунта — тоже открывает Key Backup.
  4. Не жмите «Пропустить», если хотите читать старую историю. Если пропустили — вернуться можно позже: Настройки → Безопасность → Шифрование → Восстановить.

4. Подтвердите новое устройство

VaVsta может предложить подтвердить устройство: откройте в старом Element Настройки → Сессии (или уведомление о новом устройстве) и подтвердите вход по QR-коду или сверив эмодзи.

5. Проверьте историю

Откройте старый зашифрованный чат в VaVsta. Сообщения расшифровываются — переезд удался.

6. Попрощайтесь со старым приложением

  1. В старом Element: Настройки → Безопасность и конфиденциальность → Сессии — завершите сессию на этом устройстве.
  2. Можете удалить Element.

Что если ничего не восстановить?

Если нет ни recovery key, ни доступа к старому устройству — расшифровать старые сообщения невозможно, это свойство сквозного шифрования (и на сервере тоже никто этого не может).

В этом случае войдите и сбросьте шифрование: Настройки → Безопасность → Шифрование → Сбросить. Новые сообщения будут читаться, старые останутся зашифрованными. Важное из старых пересылайте заранее, пока оно видно со старого устройства.

💡 То же самое работает и для десктопа: зайдите на chat.vavsta.ru в браузере, войдите и восстановите ключи. Key Backup действует на любом количестве устройств.
